# Go Easy Starter 架构说明

本文说明首版模块边界和实现约定。启动步骤见 [README](../../../README.md)，实际验证范围见 [测试文档](../../testing.md)。

## 项目定位

提供可承接新业务的 GoFrame API 基础工程，包含用户认证、文件存储、缓存、队列、周期调度、可选 WebSocket 和独立 CRUD 示例。

项目通过文件与环境变量配置外部服务；不依赖其他应用的数据库、配置中心、用户模型、业务任务或运行资源。

## 技术基线

| 项目 | 实现 |
| --- | --- |
| Go | 1.26.10+ |
| Web / ORM / 日志 / 代码生成 | GoFrame v2.7.2，项目 CLI 使用相同版本 |
| 数据库 | PostgreSQL，SQL 显式初始化和迁移 |
| 会话与缓存 | GoFrame Redis 接入，分别配置 DB 和键前缀 |
| 认证 | JWT Access Token、轮换 Refresh Token、bcrypt 密码哈希 |
| 队列与周期调度 | Asynq |
| WebSocket | gorilla/websocket，默认关闭 |
| 文件 | 本地、UCloud、COS、OSS、七牛、MinIO |

## 分层与生命周期

调用方向为 `api → controller → service → logic → dao → PostgreSQL`。

- API 定义路由、请求、响应和校验。
- Controller 读取当前身份并调用 Service。
- Logic 处理规则、归属校验和事务。
- Service、DAO、DO、Entity 通过 GoFrame CLI 生成；对外模型单独放在 `internal/model/view`。
- `internal/bootstrap/app.go` 按角色显式创建和关闭资源，导入业务包不会自动连接外部服务。
- 公共认证、存储和缓存组件不依赖业务 Logic。

| 角色 | 功能 |
| --- | --- |
| `http` | API、任务生产者、启用的存储、可选 WebSocket |
| `queue` | 任务消费者、数据库幂等示例、本地临时文件清理 |
| `scheduler` | 仅连接队列 Redis，投递周期任务 |
| `all` | 本地组合运行以上角色 |

收到退出信号后停止调度、关闭连接并等待请求与任务结束，再释放数据库和 Redis。生产同一部署只运行一个 Scheduler。

## 用户与会话

- 账号密码注册、登录、本人资料修改、修改密码、退出；注册入口可关闭，没有固定演示账号。
- 用户名规范化并使用数据库唯一约束；密码使用 bcrypt，不返回哈希或凭证版本。
- 单用户单会话，新登录替换旧会话。
- Access Token 默认 15 分钟，Refresh Token 空闲 7 天、绝对有效期 30 天，并发刷新宽限 5 秒。
- Redis 保存刷新凭证摘要，Lua 原子轮换；短期并发结果加密回放。
- 宽限期外重用已消费的有效刷新凭证撤销会话，无效输入不能撤销其他会话。
- 修改密码与 `credential_version` 递增在同一数据库事务中完成；HTTP、刷新和 WebSocket 均检查当前账号状态与凭证版本。
- 普通受保护接口使用 `Authorization: Bearer ...`；Redis 故障时返回错误，不绕过会话校验。

## 文件与存储

六种驱动提供普通上传、删除、公开或短期私有链接。默认只启用本地驱动，云凭证按需配置。

附件记录稳定的存储名称、驱动、桶、对象键和归属。修改默认存储只影响新上传；已有附件仍使用其原存储配置。数据库不保存过期签名 URL，链接按需生成。

上传校验大小、实际 MIME、扩展名和 SHA-256；对象键由服务端生成。不跨用户复用附件权限。对象写入后再登记元数据，登记失败尝试补偿删除；不宣称数据库与对象存储构成分布式事务。

附件列表、元数据、签名地址、删除及分片操作均检查归属。头像只能引用本人附件，引用存在时删除返回 409，数据库组合外键提供最终约束。

本地分片支持初始化、进度、乱序分片、按数字顺序合并、摘要校验和重复完成；文件锁和附件 `upload_id` 唯一约束协调并发与重启。过期临时文件由周期任务清理。云分片明确返回 501 `STORAGE_CAPABILITY_UNSUPPORTED`。

本地私有文件通过签名下载接口访问，目录不挂静态服务；多实例需要共享持久目录和兼容的文件锁。云端私密性仍由桶权限决定。

## 数据库与缓存

| 表 | 用途 |
| --- | --- |
| `users` | 账号、密码哈希、昵称、头像、状态、凭证版本 |
| `attachments` | 文件归属、稳定存储标识、大小、摘要与可见性 |
| `example_items` | 归属当前用户的分页 CRUD 和任务计数 |
| `example_task_receipts` | 事务幂等记录 |

初始化使用 `manifest/sql/001_init.sql`、`002_example.sql`；`make db-init` 在事务内执行，已有用户表时拒绝重复初始化。程序启动不自动修改表结构。

数据库时间使用 `timestamptz`，对外 View 使用 RFC3339。单行新增通过参数化 `INSERT ... RETURNING id` 获取主键，兼容 PostgreSQL 18 与固定版本驱动的组合。

Redis 配置区分认证、JSON 缓存和队列。缓存 TTL 必须显式指定；认证和缓存使用独立前缀，Asynq 使用自身键结构，不同应用的队列使用独立 Redis DB 或实例。

## 队列与 WebSocket

队列提供即时、延迟、重试、6/3/1 权重优先级、并发和处理超时。示例包含日志、事务幂等数据更新、过期本地分片清理。处理失败返回错误，确定无法执行的无效负载跳过重试。

任务可能重复处理；业务通过事务和唯一键保证幂等。Scheduler 仅投递，消费者执行实际操作。

WebSocket 默认关闭。客户端先通过受保护接口换取一次性短期票据，再建立连接。连接有来源、数量、大小和心跳限制，每个连接单独写协程，消息与心跳核对会话。用户推送只覆盖当前进程，不提供跨实例广播总线。

## HTTP 与开发交付

普通业务响应为 `{code,msg,data,traceId,reason?}`，同时使用实际 HTTP 状态码；下载和 WebSocket 使用原始协议。

提供参数校验、分页、CORS、Redis 限流、请求上下文、健康检查和开发环境 Swagger。日志不记录请求正文、Authorization 或查询参数。

交付内容包括配置样例、随机密钥生成、Makefile、固定版本代码生成工具、本地依赖 Compose、非 root Docker 镜像、systemd 模板和 CI。

首版范围不包含运营后台、权限平台、多租户、支付、短信或特定应用业务。示例模块可按 [开发文档](../../development.md) 独立移除。
